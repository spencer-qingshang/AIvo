## 3.  MySQL 数据库和表

### 1.  学习目的与要求

本章主要介绍 MySQL 数据库的创建、选择、修改和删除，表的基本概念，数据类型，创建表，查看表、修改表、删除表，存储引擎等内容，培养学生创建、修改、删除、选择数据库和创建、修改、删除和查看表的能力。

本章要求考生掌握 MySQL 数据库、表和数据完整性概念，具备使用 CREATE DATABASE 语句、ALTER DATABASE 语句、DROP DATABASE 语句、USE 语句分别创建数据库、修改数据库、删除数据库和选择数据库的能力，具备使用 CREATE TABLE 语句、ALTER TABLE 语句、DROP TABLE 语句、SHOW TABLES 语句分别创建表、修改表、删除表和查看表的能力。

### 2.  课程内容

1.  MySQL 数据库简介

2.  定义数据库

3.  表的基本概念

4.  数据类型

5.  定义表

### 3.  考核知识点与考核要求

#### 1.  MySQL 数据库简介

识记：使用 SHOW DATABASES 命令查看已有的数据库。

#### 2.  定义数据库

识记：定义数据库的语句：CREATE DATABASE 语句、ALTER DATABASE 语句、DROP DATABASE 语句、USE 语句。

简单应用：CREATE DATABASE 语句、ALTER DATABASE 语句、DROP DATABASE 语句、USE 语句的使用。

#### 3.  表的基本概念

识记：表的基本概念、表的组成。

领会：表结构的含义；表、列和属性的关系；表结构的组成。

#### 4.  数据类型

识记：MySQL 中常用的数据类型。

领会：MySQL 中常用的数据类型的含义、数字类型的选择、数据类型的选择应遵循的原则。

#### 5.  定义表

识记：创建表、查看表、修改表、删除表使用的语句。

简单应用：使用 CREATE TABLE 语句、ALTER TABLE 语句、DROP TABLE 语句、SHOW TABLES 语句分别创建表、修改表、删除表和查看表。

### 4.  本章重点、难点

本章的重点：掌握创建表、修改表、删除表和查看表的语句和方法。

本章的难点：使用 CREATE TABLE 语句、ALTER TABLE 语句、DROP TABLE 语句、SHOW TABLES 语句分别创建表、修改表、删除表和查看表。
