## 1.1 命题与命题联结词

### 1.1.1 命题与命题的表示

#### 什么是命题

命题是一个能够判断真或假的陈述句。判断时检查两个条件：

1. 它是陈述句。
2. 它具有唯一的真值。

真值只有两种：

- 真：`T`
- 假：`F`

“目前不知道真假”不等于没有唯一真值。例如“宇宙中存在地球以外的生命”客观上一定为真或假，只是我们目前不知道是哪一种；它仍然是命题。“未知”不是第三种真值。

变量没有指定时，语句可能不具有唯一真值。例如 `x+1=2` 会随 `x` 的取值改变真假，所以在 `x` 未指定时不是命题。

| 语句 | 是否为命题 | 原因 |
| --- | --- | --- |
| 2 是偶数 | 是，真 | 陈述句且真值唯一 |
| 3 大于 10 | 是，假 | 假命题仍然是命题 |
| 你吃饭了吗？ | 否 | 疑问句 |
| 请关门！ | 否 | 祈使句 |
| `x+1=2` | 否（`x` 未指定时） | 真值随 `x` 改变 |

#### 命题的符号化

常用大写字母表示命题：

```text
P：10 是偶数
P=T
```

- 冒号 `：` 后面写命题内容。
- 等号（=）后面写真值。
- `P、Q、R` 只是命题的名称，没有固定含义。

#### 本节学习记录

- 状态：已掌握
- 无辅助检测：通过

- 易错点：不要把命题内容写成 `P=某句话`；应写成 `P：某句话`。

### 1.1.2 原子命题、复合命题与联结词

#### 原子命题与复合命题

- **原子命题**：不含命题联结词、不能再按逻辑结构拆分的命题。
- **复合命题**：由原子命题通过联结词构成的命题。

`P` 可以是原子命题；`¬P` 使用了否定联结词，因此是复合命题。

#### 五种联结词

##### 1. 否定 `¬`

`¬P` 读作“非 P”，表示 P 不成立。它会把 P 的真值翻转。

| P | ¬P |
| --- | --- |
| T | F |
| F | T |

不等式的否定要覆盖全部剩余情况：

```text
¬(x<4) 是 x≥4
¬(x>4) 是 x≤4
```

##### 2. 合取 `∧`

`P ∧ Q` 读作“P 且 Q”。两者都为真时才为真。

| P | Q | P ∧ Q |
| --- | --- | --- |
| T | T | T |
| T | F | F |
| F | T | F |
| F | F | F |

简记：**全真才真，一假则假。**

##### 3. 析取 `∨`

`P ∨ Q` 读作“P 或 Q”。离散数学默认使用包容或：至少一个为真就为真，两个都真时也为真。

| P | Q | P ∨ Q |
| --- | --- | --- |
| T | T | T |
| T | F | T |
| F | T | T |
| F | F | F |

简记：**一真则真，全假才假。**

##### 4. 蕴含 `→`

`P → Q` 读作“如果 P，那么 Q”。P 是前件（条件），Q 是后件（结果）。

| P | Q | P → Q |
| --- | --- | --- |
| T | T | T |
| T | F | F |
| F | T | T |
| F | F | T |

简记：**只有真推出假时为假。**

说明蕴含为假的理由时，必须同时写出：

> 前件为真，说明条件已经发生；后件为假，说明结果没有发生。

不能只写“后件为假”，因为 `F → F` 仍然为真。

##### 5. 等价 `↔`

`P ↔ Q` 读作“P 当且仅当 Q”。P、Q 的真值相同时为真，不同时为假。

| P | Q | P ↔ Q |
| --- | --- | --- |
| T | T | T |
| T | F | F |
| F | T | F |
| F | F | T |

简记：**同真同假为真，一真一假为假。**固定说法是“当且仅当”，不是“并且仅当”。

#### 五种联结词速记

| 名称 | 符号 | 判断规律 |
| --- | --- | --- |
| 否定 | `¬P` | 真假翻转 |
| 合取 | `P ∧ Q` | 全真才真 |
| 析取 | `P ∨ Q` | 一真则真 |
| 蕴含 | `P → Q` | 只有真推假为假 |
| 等价 | `P ↔ Q` | 真值相同为真 |

#### 无辅助检测记录

设：

- `P`：9 是奇数，`P=T`。
- `Q`：9 是素数，`Q=F`。

已独立完成 `¬P`、`P ∧ Q`、`P ∨ Q`、`P → Q`、`Q → P`、`P ↔ Q` 的真值判断，所有真值均正确。

- 检测前信心：100 分
- 检测后信心：90 分
- 独立表现：强
- 易错点：写自然语言时，要把 `P、Q` 还原成完整的命题内容。
- 易错点：说明 `P → Q` 为假时，要写“前件为真、后件为假”。
- 反思：信心降低主要来自蕴含命题的理由表述。

## 1.2 命题公式的等值演算

> 当前进度：1.2.1 已掌握；1.2.2 待学习。

### 1.2.1 命题公式

#### 命题常项与命题变元

- **命题常项**：表示某个具体命题，真值已经确定。
- **命题变元**：可以代表任意命题；在没有赋值前，真值不确定。

命题公式是按照规定的逻辑语法，由命题常项或命题变元、联结词和括号有限次组成的式子。

构成规则：

1. 单个命题变元或命题常项是命题公式，也叫原子公式。
2. 如果 $A$ 是公式，那么 $\neg A$ 是公式。
3. 如果 $A、B$ 是公式，那么 $A\land B$、$A\lor B$、$A\to B$、$A\leftrightarrow B$ 都是公式。
4. 只有按照上述规则有限次构成的符号串才是公式。

例如：

```text
¬P ∨ Q
(P ∧ Q) → R
```

`P ∨ → Q` 不是命题公式，因为两个二元联结词直接相连，中间缺少公式。

#### 括号和运算顺序

没有括号时，教材中的常用运算顺序为：

1. `¬`
2. `∧`
3. `∨`
4. `→`
5. `↔`

初学时优先写括号，避免误解运算范围。

例如：

```text
P ∧ Q → R      表示 (P ∧ Q) → R
P ∨ Q ∧ R      表示 P ∨ (Q ∧ R)
¬P ∨ Q         表示 (¬P) ∨ Q
```

#### 最外层联结词与子公式

找公式结构时，从最外层联结词开始拆分，再继续拆左右部分，直到原子公式。

例如：

```text
(P ∧ Q) ↔ ¬R
```

- 最外层联结词：$\leftrightarrow$
- 直接连接的左边：$P\land Q$
- 直接连接的右边：$\neg R$
- 全部子公式：$P、Q、R、P\land Q、\neg R、(P\land Q)\leftrightarrow\neg R$

整个公式本身也算它自己的子公式。

#### 赋值

给公式中的每个命题变元指定真值，叫作一次赋值或真值指派。

如果按照 $P、Q、R$ 的顺序给出：

```text
P 为假，Q 为真，R 为假
```

可以简写为 $(F,T,F)$。赋值是事先给定的条件，不是公式计算出来的结果。

含有 $n$ 个不同命题变元的公式共有 $2^n$ 种赋值。三个命题变元的标准排列是：

| $P$ | $Q$ | $R$ |
| --- | --- | --- |
| T | T | T |
| T | T | F |
| T | F | T |
| T | F | F |
| F | T | T |
| F | T | F |
| F | F | T |
| F | F | F |

排列规律：第一列每 4 行变化，第二列每 2 行变化，第三列每 1 行变化。

#### 真值表

真值表列出所有可能的赋值，并逐行计算公式的真值。复合公式应增加中间列，按照运算顺序逐步计算。

例如 $A=\neg P\lor Q$：

| $P$ | $Q$ | $\neg P$ | $\neg P\lor Q$ |
| --- | --- | --- | --- |
| T | T | F | T |
| T | F | F | F |
| F | T | T | T |
| F | F | T | T |

检测公式：

### 1.2.2 等值演算与蕴涵式

两个命题公式在所有可能的真值组合下结果都相同，称为等值，记作 `≡`。

已经接触但需要重新学习和检测的等值式：

```text
¬¬P ≡ P
¬(P ∨ Q) ≡ ¬P ∧ ¬Q
¬(P ∧ Q) ≡ ¬P ∨ ¬Q
P → Q ≡ ¬P ∨ Q
P ↔ Q ≡ (P → Q) ∧ (Q → P)
```

判断等值最可靠的方法是列出真值表，检查两个公式在每一行的结果是否完全相同。

#### 待完成练习

设 `P=T，Q=F`，重新学习后独立计算：

1. `P → Q`
2. `¬P ∨ Q`
3. `P ↔ Q`
4. `¬(P ∧ Q) ∨ P`
5. 判断 `P → Q` 与 `¬P ∨ Q` 是否等值，并说明依据。

#### 等值、蕴涵与等价式的完整复习

设 `A`、`B` 为命题公式。

- **等值**：若在每一种赋值下 `A`、`B` 的真值完全相同，则称 `A` 与 `B` 等值，记作 `A ≡ B`。等价地说，`A ↔ B` 是永真式。
- **逻辑蕴涵**：若在每一种赋值下，只要 `A` 为真，`B` 就必为真，则称 `A` 蕴涵 `B`，记作 `A ⇒ B`。等价地说，`A → B` 是永真式。
- **反例判定**：要否定 `A ⇒ B`，只需找一组赋值使 `A=T`、`B=F`。这是蕴涵唯一可能失败的情形，即 `T → F = F`。

`→` 是公式内部的联结词；`⇒` 是两个公式之间的逻辑关系。不要把 `⇒` 当成“等于”或 `↔`。

##### 两种验证方法

1. **真值表法**：逐行比较 `A`、`B` 的最终列；全部相同才等值。对蕴涵 `A ⇒ B`，检查 `A → B` 的最终列是否全为 `T`。
2. **等值演算法**：每一步只替换一个与当前子公式等值的部分；最后写出每一步依据，避免跳步。

##### 常用等值式

| 名称 | 等值式 |
| --- | --- |
| 双重否定 | `¬¬A ≡ A` |
| 交换律 | `A ∨ B ≡ B ∨ A`；`A ∧ B ≡ B ∧ A` |
| 结合律 | `A ∨ (B ∨ C) ≡ (A ∨ B) ∨ C`；`A ∧ (B ∧ C) ≡ (A ∧ B) ∧ C` |
| 分配律 | `A ∨ (B ∧ C) ≡ (A ∨ B) ∧ (A ∨ C)`；`A ∧ (B ∨ C) ≡ (A ∧ B) ∨ (A ∧ C)` |
| 吸收律 | `A ∨ (A ∧ B) ≡ A`；`A ∧ (A ∨ B) ≡ A` |
| 同一律 | `A ∨ F ≡ A`；`A ∧ T ≡ A` |
| 零律 | `A ∨ T ≡ T`；`A ∧ F ≡ F` |
| 排中律 / 矛盾律 | `A ∨ ¬A ≡ T`；`A ∧ ¬A ≡ F` |
| 德摩根律 | `¬(A ∨ B) ≡ ¬A ∧ ¬B`；`¬(A ∧ B) ≡ ¬A ∨ ¬B` |
| 蕴涵等值式 | `A → B ≡ ¬A ∨ B` |
| 等价等值式 | `A ↔ B ≡ (A → B) ∧ (B → A)` |
| 假言易位 | `A → B ≡ ¬B → ¬A` |

##### 高频推导

```text
¬(P → Q)
≡ ¬(¬P ∨ Q)       （蕴涵等值式）
≡ ¬¬P ∧ ¬Q         （德摩根律）
≡ P ∧ ¬Q           （双重否定）
```

这说明“P 推出 Q 不成立”恰好是“P 真且 Q 假”。

##### 易错点

- `¬(P ∨ Q)` 必须变为 `¬P ∧ ¬Q`；否定进入括号后，每个命题取反，同时 `∨`、`∧` 互换。
- `¬P ∨ ¬Q` 表示“并非 P、Q 同时为真”，即 `¬(P ∧ Q)`，它不是 `P ∧ Q`。
- 验证 `A ⇒ B` 时，只看是否能出现“左真右假”；左边为假不会推翻蕴涵。

## 1.3 联结词完备集

- 教材页码：32-33

### 定义

联结词集合 `S` 称为**完备集**，是指任意 `n (n≥1)` 元真值函数都能由 `S` 中的联结词构成的公式表示。对本章而言，可把它理解为：用这组联结词能表示任意命题公式。

五个基本联结词 `{¬, ∧, ∨, →, ↔}` 本身当然是完备集；更重要的是，有些更小的集合也足够。

### 由等值式逐步删减联结词

```text
A ↔ B ≡ (A → B) ∧ (B → A)    可去掉 ↔
A → B ≡ ¬A ∨ B                可去掉 →
¬(A ∨ B) ≡ ¬A ∧ ¬B            可在 ∧、∨ 之间转换
```

因此下列都是常用的最小联结词完备集：

```text
{¬, ∨}
{¬, ∧}
{¬, →}
```

### `{¬, ∨}` 的构造模板

| 原联结词 | 只用 `¬`、`∨` 的表示 |
| --- | --- |
| `P ∧ Q` | `¬(¬P ∨ ¬Q)` |
| `P → Q` | `¬P ∨ Q` |
| `P ↔ Q` | `¬(¬P ∨ ¬Q) ∨ ¬(P ∨ Q)` |

必须区分：

```text
P ∧ Q ≡ ¬(¬P ∨ ¬Q)
¬(P ∧ Q) ≡ ¬P ∨ ¬Q
```

外层的 `¬` 决定了这两式不是同一个公式。

### 与非、或非

教材还定义了两种常见联结词：

```text
P ↑ Q ≡ ¬(P ∧ Q)    （与非）
P ↓ Q ≡ ¬(P ∨ Q)    （或非）
```

单独的 `{↑}` 和 `{↓}` 也都是完备集。这一结论在逻辑电路中很重要。

### 自检清单

学习完本节应能：

1. 说明“完备”指能表示任意命题公式，不是“联结词数量多”。
2. 用 `¬`、`∨` 写出 `P ∧ Q`。
3. 用 `¬`、`∨` 写出 `P → Q`。
4. 区分 `P ∧ Q` 与 `¬(P ∧ Q)` 的等值表达。
