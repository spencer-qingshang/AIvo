### 第32题（5分）

chunks.txt恰含ASCII文字abcdef，随后一个换行，再有文字XY及一个换行。文件已存在，假设正常读取。写出三次fgets读取所得字符串长度的完整输出，注意缓冲区容量。

```cpp
#include <iostream>
#include <cstdio>
#include <cstring>
using namespace std;
int main()
{
    FILE *fp=fopen("chunks.txt","r");
    char line[4];
    for(int i=0;i<3;++i) {
        fgets(line,4,fp);
        if(i>0) cout << ' ';
        cout << strlen(line);
    }
    cout << '\n';
    fclose(fp);
    return 0;
}
```
