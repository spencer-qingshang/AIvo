## SQL 核心清单

优先做到能解释并手写这些结构：

```sql
CREATE DATABASE School;
CREATE TABLE Student (
    StudentId INT PRIMARY KEY,
    Name VARCHAR(30) NOT NULL
);
SELECT column_list FROM table_name WHERE condition;
SELECT ... FROM A INNER JOIN B ON A.key = B.key;
INSERT INTO table_name (...) VALUES (...);
UPDATE table_name SET column_name = value WHERE condition;
DELETE FROM table_name WHERE condition;
```

## 易错提醒

- 主键要求唯一且不能为 NULL；外键用于表达表之间的参照关系，不等于“任意一列”。
- `WHERE` 在分组前筛选行，`HAVING` 在 `GROUP BY` 后筛选组。
- `INNER JOIN` 不会保留没有匹配项的行；写连接条件时要先确认两个表的关联字段。
- `DELETE` 删除行，`DROP` 删除对象，`TRUNCATE` 清空表数据但语义和日志行为不同。
- 索引会提升部分读取速度，但会增加写入维护成本；不是列越多越好。
- 事务的“原子性”不是“操作很快”，而是操作要么全部成功，要么全部撤销。
