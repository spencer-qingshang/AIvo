## 第7章数据完整性选择题

以下均为单项选择题，每题只有一个正确答案。

### 1. 数据完整性的主要含义是（B ）。

A. 保证数据库中数据的安全性  
B. 保证数据库中数据的正确性、有效性和一致性  
C. 提高数据库的查询速度  
D. 防止用户登录数据库

### 2. 使用数据完整性约束机制的主要优点是（B ）。

A. 完全不需要编写 SQL 语句  
B. 由数据库系统自动检查和维护数据的正确性  
C. 可以提高所有查询语句的执行速度  
D. 可以替代数据库备份

### 3. MySQL 中不属于数据完整性类型的是（D ）。

A. 实体完整性  
B. 参照完整性  
C. 用户定义的完整性  
D. 网络完整性

### 4. 实体完整性主要通过（A ）实现。

A. PRIMARY KEY 约束  
B. FOREIGN KEY 约束  
C. CHECK 约束  
D. DEFAULT 约束

### 5. 关于主键的说法，正确的是（B ）。

A. 主键列允许出现 NULL  
B. 一个表只能有一个主键  
C. 主键列允许出现重复值  
D. 主键只能由一个字段组成

A. 主键可以由一个字段组成  
B. 主键可以由多个字段组成  
C. 主键值必须唯一  
D. 一个表可以定义多个 PRIMARY KEY 约束

### 7. 下列关于 UNIQUE 约束的说法，正确的是（A ）。

A. UNIQUE 约束要求列值不能重复  
B. UNIQUE 约束一定要求列不能为 NULL  
C. 一个表只能设置一个 UNIQUE 约束  
D. UNIQUE 约束只能用于数值类型字段

### 8. 主键约束和唯一性约束的主要区别是（B ）。

A. 主键允许重复，UNIQUE 不允许重复  
B. 主键不能为 NULL，UNIQUE 在 MySQL 中通常允许 NULL  
C. 主键只能用于字符型字段  
D. UNIQUE 不能建立索引

### 9. 下列语句中，能够正确创建主键的是（ A）。

A. `CREATE TABLE student (id INT PRIMARY(id));`  
B. `CREATE TABLE student (id INT PRIMARY KEY);`  
C. `CREATE TABLE student (id INT KEY PRIMARY);`  
D. `CREATE TABLE student (id INT UNIQUE PRIMARY);`

### 12. 要求 `student` 表中的 `id` 字段不能为空，通常应使用（ ）。

A. `NULL`  
B. `NOT NULL`

### 13. 非空约束的作用是（ ）。

### 14. 参照完整性主要通过（ ）实现。

A. PRIMARY KEY  
B. FOREIGN KEY

### 15. 外键通常用于建立（ ）之间的联系。

A. 两个字段

A. 普通字段
