## 第 3 课：什么是等值

### 命题公式

用命题字母（如 `P`、`Q`）和联结词（如 `¬`、`∧`、`∨`）组成的式子，叫作命题公式。

例如：`¬P ∨ Q`，读作“非 P，或 Q”。

### 等值

两个命题公式在**所有可能的真值组合下，结果都相同**，就叫作等值，记作 `≡`。

最基础的例子：

`¬¬P ≡ P`

意思是“不是 P 的否定”等价于 P。比如“今天不是不下雨”就是“今天下雨”。

判断等值最可靠的办法是列真值表：只要每一行的结果都相同，就等值。

| P | ¬P | ¬¬P |
| --- | --- | --- |
| 真 | 假 | 真 |
| 假 | 真 | 假 |

可以看到，`¬¬P` 和 `P` 的结果完全一样，所以它们等值。

## 本节小练习（请你作答）

设 `P` 为假，`Q` 为真：

1. `¬¬P` 的真值是什么？
2. `P ∨ Q` 的真值是什么？
3. `¬(P ∨ Q)` 的真值是什么？

## 补充讲解：为什么 `¬(P ∨ Q) ≡ ¬P ∧ ¬Q`

先把两边翻译成普通话：

- 左边 `¬(P ∨ Q)`：**P 和 Q 至少有一个为真**这件事不成立。
- 右边 `¬P ∧ ¬Q`：P 是假，**并且** Q 也是假。

`P ∨ Q` 只有在 P、Q 都假时才是假；给它加上“非”以后，便只有 P、Q 都假时才为真。右边 `¬P ∧ ¬Q` 也要求 P、Q 都假才为真，因此两边每一种情况的结果都相同。

| P | Q | P ∨ Q | ¬(P ∨ Q) | ¬P | ¬Q | ¬P ∧ ¬Q |
| --- | --- | --- | --- | --- | --- | --- |
| 真 | 真 | 真 | 假 | 假 | 假 | 假 |
| 真 | 假 | 真 | 假 | 假 | 真 | 假 |
| 假 | 真 | 真 | 假 | 真 | 假 | 假 |
| 假 | 假 | 假 | 真 | 真 | 真 | 真 |

观察倒数第二列和最后一列：四行都一样，所以两个公式等值。

当 `P` 为假、`Q` 为真时，计算顺序如下：

1. `P ∨ Q`：假或真，结果为真。
2. `¬(P ∨ Q)`：对“真”取非，结果为假。
3. `¬P ∧ ¬Q`：P 为假，所以 `¬P` 为真；Q 为真，所以 `¬Q` 为假；真且假，结果为假。

因此在这一组条件下，两边都为假。

## 第二条德摩根律

同样地：

`¬(P ∧ Q) ≡ ¬P ∨ ¬Q`

记法：**“且”的否定 = 两边都否定，再用“或”连接。**

确认题：当 `P` 为真、`Q` 为假时，`P ∧ Q` 为假，`¬(P ∧ Q)` 为真。已正确完成。

## 蕴含：`P → Q`

`P → Q` 读作“如果 P，那么 Q”。它**只有一种情况为假**：P 为真，但 Q 为假。

| P | Q | P → Q |
| --- | --- | --- |
| 真 | 真 | 真 |
| 真 | 假 | 假 |
| 假 | 真 | 真 |
| 假 | 假 | 真 |

可以把它理解为一个承诺：“如果你完成作业（P），我就给你奖励（Q）。”只有你完成了作业、却没有得到奖励时，这个承诺才被打破。

最重要的等值式：

`P → Q ≡ ¬P ∨ Q`

也就是说，“如果 P 那么 Q”等价于“P 不成立，或者 Q 成立”。

## 双条件：`P ↔ Q`

`P ↔ Q` 读作“P 当且仅当 Q”。P 和 Q 真值相同，结果就为真；不同就为假。

| P | Q | P ↔ Q |
| --- | --- | --- |
| 真 | 真 | 真 |
| 真 | 假 | 假 |
| 假 | 真 | 假 |
| 假 | 假 | 真 |

它可以理解为“两边互相保证”：

`P ↔ Q ≡ (P → Q) ∧ (Q → P)`

## 运算顺序

没有括号时，按下面顺序计算：

1. `¬` 非
2. `∧` 且
3. `∨` 或
4. `→` 蕴含
5. `↔` 双条件

不过初学时建议主动加括号，不靠死记顺序。例如写成 `¬(P ∨ Q)`，比直接写 `¬P ∨ Q` 更不容易误解。

## 用 C/C++ 的 if 语句记忆

把命题 `P`、`Q` 当作两个布尔变量：

```cpp
bool P = true;
bool Q = false;
```

逻辑符号和 C/C++ 运算符的对应关系：

| 离散数学 | C/C++ | 含义 |
| --- | --- | --- |
| `¬P` | `!P` | 非 P |
| `P ∧ Q` | `P && Q` | P 且 Q |
| `P ∨ Q` | `P || Q` | P 或 Q |
| `P ↔ Q` | `P == Q` | P、Q 真值相同 |

### “且”就是 if 中两个条件都满足

```cpp
if (P && Q) {
    // 只有 P 和 Q 都为 true 才执行
}
```

### “或”就是 if 中至少一个条件满足

```cpp
if (P || Q) {
    // P、Q 至少一个为 true 就执行
}
```

### 德摩根律就是把 if 条件整体取反

```cpp
if (!(P || Q)) {
    // 等价条件：!P && !Q
}
```

因此：

```cpp
!(P || Q) == (!P && !Q)
!(P && Q) == (!P || !Q)
```

记忆方法：`!` 进入括号后，每个条件都取反，同时 `||` 与 `&&` 互换。

### 蕴含可以写成 `!P || Q`

离散数学中的：

`P → Q ≡ ¬P ∨ Q`

对应 C/C++：

```cpp
bool implication = !P || Q;
```

它只有在 `P == true` 且 `Q == false` 时为假。也可以从“违约条件”理解：

```cpp
if (P && !Q) {
    // P 成立但 Q 不成立：P → Q 被破坏
}
```

### 双条件就是两个布尔值相同

```cpp
if (P == Q) {
    // P、Q 同真或同假，对应 P ↔ Q 为真
}
```
