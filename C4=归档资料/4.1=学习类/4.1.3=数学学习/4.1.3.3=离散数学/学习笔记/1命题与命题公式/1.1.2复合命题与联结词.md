# 1.1.2复合命题与联结词

- 教材页码：19
- 来源：02324《离散数学》（2014 年版）

## 第 2 课：原子命题、复合命题与五种联结词

不含命题联结词、不能再按逻辑结构拆分的命题，叫作**原子命题**。由原子命题通过联结词构成的命题，叫作**复合命题**。即使只作用于一个原子命题，`¬P` 也使用了否定联结词，因此是复合命题。

设：

- `P`：今天下雨。
- `Q`：我带伞。

### 1. 非：`¬P`

`¬P` 读作“非 P”，意思是“P 不成立”。它会把真值反过来。

| P | ¬P |
| --- | --- |
| 真 | 假 |
| 假 | 真 |

例如：如果“今天下雨”为真，那么“今天不下雨”就是假。

### 2. 且：`P ∧ Q`

`P ∧ Q` 读作“P 且 Q”。**只有 P 和 Q 都为真时，它才为真。**

例如：“今天下雨，并且我带伞”。下雨但没带伞，整个句子仍为假。

| P | Q | P ∧ Q |
| --- | --- | --- |
| 真 | 真 | 真 |
| 真 | 假 | 假 |
| 假 | 真 | 假 |
| 假 | 假 | 假 |

### 4. 蕴含：`P → Q`

`P → Q` 读作“如果 P，那么 Q”。P 是前件（条件），Q 是后件（结果）。只有前件为真、后件为假时，整个蕴含命题才为假。

| P | Q | P → Q |
| --- | --- | --- |
| 真 | 真 | 真 |
| 真 | 假 | 假 |
| 假 | 真 | 真 |
| 假 | 假 | 真 |

简记：**真推出假，才是假。**答题理由必须同时说明“条件发生”和“结果没有发生”，不能只说后件为假。

### 5. 等价：`P ↔ Q`

`P ↔ Q` 读作“P 当且仅当 Q”。P、Q 真值相同时为真，真值不同时为假。

| P | Q | P ↔ Q |
| --- | --- | --- |
| 真 | 真 | 真 |
| 真 | 假 | 假 |
| 假 | 真 | 假 |
| 假 | 假 | 真 |

简记：**同真同假为真，一真一假为假。**固定说法是“当且仅当”，不是“并且仅当”。

### 3. 或：`P ∨ Q`

`P ∨ Q` 读作“P 或 Q”。离散数学中默认是**包容或**：至少一个为真就为真，两个都真也算真。

例如：“今天下雨，或者我带伞”。只要下雨或带伞两件事中有一件成立，整个句子就成立。

| P | Q | P ∨ Q |
| --- | --- | --- |
| 真 | 真 | 真 |
| 真 | 假 | 真 |
| 假 | 真 | 真 |
| 假 | 假 | 假 |

## 五种联结词速记

| 名称 | 符号 | 判断规律 |
| --- | --- | --- |
| 否定 | `¬P` | 真假颠倒 |
| 合取 | `P ∧ Q` | 全真才真 |
| 析取 | `P ∨ Q` | 一真则真 |
| 蕴含 | `P → Q` | 只有真推假为假 |
| 等价 | `P ↔ Q` | 真值相同为真 |
