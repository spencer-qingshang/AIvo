## 6.  视图和索引

### 1.  学习目的与要求

本章学习视图、索引的概念及其作用。

本章要求考生理解视图和索引的概念，并掌握创建视图、修改视图、删除视图、查询视图的语句和方法，掌握更新视图的方法，掌握三种创建索引的方法和两种删除索引的语句和方法。

### 2.  课程内容

1.  视图及其作用

2.  视图操作

3.  索引及其作用

4.  索引操作

### 3.  考核知识点与考核要求

#### 1.  视图及其作用

识记：视图的含义。

领会：视图的优点。

#### 2.  视图操作

识记：视图操作包括的内容。

领会：理解创建视图、修改视图、删除视图、查询视图的方法，理解 CREATE VIEW 语句、ALTER VIEW 语句、DROP VIEW 语句、SELECT 语句对视图进行查询的含义；理解更新视图的含义。

简单应用：具备使用视图操作语句分别创建视图、修改视图、删除视图、查询视图的能力；具备通过视图进行插入、删除、修改数据的能力。

#### 3.  索引及其作用

识记：索引的概念、索引的分类。

领会：正确使用索引的优点、建立索引的建议。

#### 4.  索引操作

识记：三种创建索引的方法。

领会：理解两种删除索引的方法。

简单应用：使用 CREATE INDEX 语句、ALTER TABLE 语句分别在已有的表上创建索引；使用 CREATE INDEX 语句在创建表的同时创建索引；使用 SHOW INDEX 语句查看表上建立的索引；使用 DROP INDEX 语句、ALTER TABLE 语句分别删除索引。

### 4.  本章重点、难点

本章的重点：教学重点是掌握创建视图、修改视图、删除视图、查询视图的语句和方法，掌握更新视图的方法，掌握三种创建索引的方法和两种删除索引的语句和方法。

本章的难点：使用 CREATE VIEW 语句、ALTER VIEW 语句、DROP VIEW 语句、SELECT 语句分别创建视图、修改视图、删除视图、查询视图的能力；对更新视图进行插入、删除、修改数据；使用 CREATE INDEX 语句、ALTER TABLE 语句分别创建索引的能力和使用 DROP INDEX 语句、ALTER TABLE 语句分别删除索引。
