# 1.1.2复合命题与联结词

- 教材页码：19
- 来源：02324《离散数学》（2014 年版）

## 第 2 课：非、且、或

把简单命题用“不是、并且、或者”连接起来，就得到**复合命题**。

设：

- `P`：今天下雨。
- `Q`：我带伞。

### 1. 非：`¬P`

`¬P` 读作“非 P”，意思是“P 不成立”。它会把真值反过来。

| P | ¬P |
| --- | --- |
| 真 | 假 |
| 假 | 真 |

例如：如果“今天下雨”为真，那么“今天不下雨”就是假。

### 2. 且：`P ∧ Q`

`P ∧ Q` 读作“P 且 Q”。**只有 P 和 Q 都为真时，它才为真。**

例如：“今天下雨，并且我带伞”。下雨但没带伞，整个句子仍为假。

| P | Q | P ∧ Q |
| --- | --- | --- |
| 真 | 真 | 真 |
| 真 | 假 | 假 |
| 假 | 真 | 假 |
| 假 | 假 | 假 |

### 3. 或：`P ∨ Q`

`P ∨ Q` 读作“P 或 Q”。离散数学中默认是**包容或**：至少一个为真就为真，两个都真也算真。

例如：“今天下雨，或者我带伞”。只要下雨或带伞两件事中有一件成立，整个句子就成立。

| P | Q | P ∨ Q |
| --- | --- | --- |
| 真 | 真 | 真 |
| 真 | 假 | 真 |
| 假 | 真 | 真 |
| 假 | 假 | 假 |

## 小练习（请你作答）

设 `P` 为真，`Q` 为假。判断下列命题的真值：

1. `¬P`
2. `P ∧ Q`
3. `P ∨ Q`
4. `¬Q ∧ P`

按这个格式回复即可：`1. 假；2. 假；……`

## 学习记录

- 状态：已掌握
- 复习日期：2026-07-30
- 小练习答案：
  1. `¬P` 为假。
  2. `P ∧ Q` 为假：只要有一个为假，“且”就为假。
  3. `P ∨ Q` 为真：至少有一个为真，“或”就为真。
  4. `¬Q ∧ P` 为真：先算 `¬Q`，得到真；真且真为真。
- 易错点：无。已能正确处理“非”与“且/或”的计算顺序。
