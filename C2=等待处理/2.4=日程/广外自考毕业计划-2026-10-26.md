# 广东外语外贸大学自考专本毕业计划

整理日期：2026年10月26日。

主考学校：广东外语外贸大学。专科：510201计算机应用技术；本科：080901计算机科学与技术，沿用后台已识别的原计算机及应用历史顶替关系。

**目标：争取2028年6月专科、本科同批申请毕业。** 本方案优先让两张毕业证尽早齐全，将专科高数放在最后，不追求专科先单独毕业。毕业申请批次与纸质证书实际领取时间不同。

前提：2026年10月已考的02324离散数学、13793计算机程序设计基础、13005软件工程、13009数据库原理与技术全部合格；后续考试及实践按计划通过；顶替和免考在相应截止前被认可。未通过科目需要重新排期。

日期状态：2027年1月9—10日自考及相关科目已按正式表核对。2027年4月、10月，2028年考试，以及未来实践、证书考试、论文、毕业报名窗口，均为参照已公布批次的预排；正式通知发布后需复核。

NCRE选择二级C语言；现行免考表没有将二级C++列为13013、13014的免考证书。08074、08075与13013、13014是不同课程。

专科毕业本身不会自动新增本科顶替关系；专科00022高等数学（工专）也不能直接当作本科00023高等数学（工本）。本方案使用的本科历史顶替关系，后台现在已经识别。

PETS按你的选择放在9月。用于免上述自考英语课程，三级笔试合格即可，不必为这项用途另考口试。证书或合格成绩可核验后，尽早提交免考申请并查询审核结果。

NCRE春季通过后，尽早申请13013、13014免考。PETS秋季通过后，申请专、本科英语免考。

**英语备用安排：**9月PETS需要等待成绩公布和免考审核，未必赶得上12月论文报名。建议2027年10月增加报考13000英语（专升本）；笔试通过或免考获批，任一条及时满足都可解决本科英语要求。专科英语继续使用PETS三级笔试合格申请免考，争取在2028年上半年毕业手续截止前办妥。

## 五、论文与毕业安排

你提供的《附件1：广东外语外贸大学自学考试毕业论文(设计)、商务调查报告报考条件及考试时间列表（202606）》第1页第8行，对080901、11689论文明确要求：**须通过该专业其他所有课程后方能报考。**

因此，报名论文前须完成本科所有其他课程，包括高数、普通实践，以及相应顶替、免考认可。不能按只剩本科高数也可先报论文来安排。

| 时间 | 任务 |
|---|---|
| 2027年11—12月 | 核对本科所有课程状态，尤其13004实践成绩、NCRE免考、英语成绩或免考；成绩齐全后报广外论文 |
| 2027年12月 | 争取报2028年上半年论文，具体资格及截止日期等待当批广外通知 |
| 2028年上半年 | 完成论文写作、修改、提交及广外要求的考核；同时4月考专科高数 |
| 2028年5—6月 | 核对专科英语免考、全部课程、论文成绩；按当批截止时间完成手续和前置学历登记 |
| 2028年6月 | 条件全部满足时，争取专科、本科同批申请毕业 |
| 2028年12月 | 若未赶上2027年底论文报名，且2028年下半年完成论文及全部手续，则争取此批本科毕业；其他未完成事项仍须另行顺延 |

广外论文资格表列的是所报本科专业其他所有课程，没有另列必须先拿到专科毕业证的条件。本方案据此预留本科课程全过后报论文、专科高数最后完成的路径；实际报考须通过校方资格审核。

广东允许符合条件者同批申请自考专科和本科毕业。参照2026年毕业规定，同批申请者在前置学历登记中填写申请专科毕业的准考证号，按当批截止时间办理。

## 六、近期先做的事

1. 等2026年10月四科成绩，确认全部合格；如有未通过科目，调整后续排期。
2. 按本方案选择顶替关系，重新运行专科、本科毕业预测。
3. 2026年11—12月关注1月自考报考，报13167网页设计与制作和13011人工智能与大数据。
4. 2026年12月关注广外03345、13006实践报名，同时关注NCRE二级C语言报名。
