## 5.  数据查询

### 1.  学习目的与要求

本章重点讲述使用 SELECT 查询语句对数据库进行单表查询和多表查询的各种查询方法。

本章要求考生掌握 SELECT 子句、WHERE 子句、GROUP BY 子句、HAVING 子句、ORDER BY 子句和 LIMIT 子句分别进行投影查询、选择查询、分组查询、排序查询、限制 SELECT 语句返回的行数查询。

### 2.  课程内容

1.  SELECT 语句

2.  投影查询

3.  选择查询

4.  分组查询和统计计算

5.  排序查询和限制查询结果的数量

6.  连接查询

7.  子查询

8.  联合查询

### 3.  考核知识点与考核要求

#### 1.  SELECT 语句

识记：SELECT 语句包含的子句及其各子句的功能。

#### 2.  投影查询

识记：投影查询的含义。

简单应用：能正确使用 SELECT 子句进行投影查询，包括投影指定的列、投影全部列、修改查询结果的列标题、计算列值、去掉重复行等。

#### 3.  选择查询

识记：选择查询的含义。

领会：LIKE 关键字和 REGEXP 关键字的异同。

简单应用：能正确使用 WHERE 子句进行选择查询，包括使用表达式比较、指定范围、空值判断、使用 LIKE 关键字的字符串匹配查询、使用正则表达式查询等。

#### 4.  分组查询和统计计算

识记：聚合函数的含义、GROUP BY 子句和 HAVING 子句的含义。

简单应用：正确使用聚合函数、GROUP BY 子句和 HAVING 子句进行分组查询和统计计算。

#### 5.  排序查询和限制查询结果的数量

识记：ORDER BY 子句、LIMIT 子句的语法格式。

简单应用：正确使用 ORDER BY 子句和 LIMIT 子句进行排序查询和限制查询结果的数量。

#### 6.  连接查询

识记：连接查询包括的方式；交叉连接的含义；等值连接、非等值连接、自然连接、自连接的含义。

领会：单表查询和多表查询的异同；内连接和外连接的区别；左外连接、右外连接和全外连接的区别；INNER JOIN 和 WHERE 子句的异同。

简单应用：正确使用内连接、外连接和交叉连接语句进行连接查询。

#### 7.  子查询

识记：子查询的含义。

领会：IN 子查询、比较子查询和 EXISTS 子查询的含义。

简单应用：正确使用 IN 谓词实现子查询和父查询的连接；正确使用比较子查询进行父查询与子查询之间的关联；正确使用 EXISTS 谓词测试子查询是否返回行。

#### 8.  联合查询

识记：联合查询的概念；联合查询需要遵循的规则。

简单应用：正确使用 UNION 关键词将多个查询语句结合成一个单独的 SQL 查询语句。

### 4.  本章重点、难点

本章的重点：教学重点是掌握 SELECT 子句、WHERE 子句、GROUP BY 子句、HAVING 子句、ORDER BY 子句和 LIMIT 子句分别进行投影查询、选择查询、分组查询、排序查询、限制 SELECT 语句返回的行数查询；掌握内连接、外连接和交叉连接语句，IN 子查询、比较子查询、EXISTS 子查询语句，和联合查询语句分别进行连接查询、子查询和联合查询。

本章的难点：SELECT 子句、WHERE 子句、GROUP BY 子句、HAVING 子句、ORDER BY 子句和 LIMIT 子句、联合查询语句。
