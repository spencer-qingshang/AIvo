# 1.1.1命题与命题的表示

- 教材页码：17
- 来源：02324《离散数学》（2014 年版）

## 本节目标

学完后，你应能判断一句话是不是命题，并能说出它的真值。

## 零基础解释

**命题**就是一个能够明确判断“真”或“假”的陈述句。

- 真值为真，记作 `T`。
- 真值为假，记作 `F`。

判断命题只看两点：

1. 它是不是陈述句。
2. 它的真假是否唯一确定。

不知道答案，不等于它不是命题。例如“宇宙中是否存在其他生命”即使我们暂时不知道答案，它依然客观上只能是真或假，因此仍是命题。

## 例子

| 句子 | 是否为命题 | 原因 |
| --- | --- | --- |
| 2 是偶数。 | 是，真 | 陈述句，真值唯一。 |
| 北京是中国的首都。 | 是，真 | 陈述句，真值唯一。 |
| 3 大于 10。 | 是，假 | 陈述句，真值唯一。 |
| 你吃饭了吗？ | 否 | 疑问句，不能直接判定真或假。 |
| 请关门。 | 否 | 祈使句，不能直接判定真或假。 |
| x + 1 = 2。 | 否（x 未指定时） | 真值会随 x 改变。 |

## 命题的表示

在离散数学里，常用大写字母表示命题，例如：

- `P`：2 是偶数。
- `Q`：3 大于 10。

以后我们会用这些字母把复杂句子写成简洁的逻辑式。

## 小练习（请你作答）

判断下列句子是不是命题；如果是，再写出真或假。

1. 5 是质数。
2. 请把书合上。
3. 太阳从西边升起。
4. x 是偶数。
5. 你喜欢离散数学吗？

你的答案可以直接按这个格式回复：`1. 是，真；2. 否；……`

## 本节小结

命题 = **陈述句** + **唯一的真值**。疑问句、祈使句、感叹句，以及变量未限定而真假会变化的句子，不是命题。
