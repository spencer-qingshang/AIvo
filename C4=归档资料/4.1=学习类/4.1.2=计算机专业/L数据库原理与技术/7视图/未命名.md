## 7.  数据完整性

### 1.  学习目的与要求

本章学习数据完整性的概念、实体完整性、参照完整性、用户定义的完整性等内容。

本章要求考生掌握 CREATE TABLE 语句，具备使用该语句分别创建 PRIMARY KEY 约束、UNIQUE 约束、FOREIGN KEY 约束、CHECK 约束的能力；掌握 ALTER TABLE 语句，具备使用该语句分别创建或删除 PRIMARY KEY 约束、UNIQUE 约束、FOREIGN KEY 约束、CHECK 约束的能力。

### 2.  课程内容

1.  数据完整性概述

2.  实体完整性

3.  参照完整性

4.  用户定义的完整性

### 3.  考核知识点与考核要求

#### 1.  数据完整性概述

识记：数据完整性的概念、数据完整性约束机制的优点。

领会：MySQL 的数据完整性类型：实体完整性、参照完整性、用户定义的完整性、完整性约束的含义。

#### 2.  实体完整性

领会：主键约束、唯一性约束的含义；两者的区别。

综合应用：在数据库设计中，正确使用语句实现实体完整性。

#### 3.  参照完整性

识记：定义外建时需要遵守的规则。

领会：参照完整性规则的含义、外键约束的含义。

简单应用：正确使用 SQL 语句创建、删除、修改外键约束。

综合应用：在数据库设计中正确使用语句实现参照完整性。

#### 4.  用户定义的完整性

识记：检查约束和非空约束的含义。

领会：检查约束和非空约束可使用的语句。

综合应用：在数据库设计中，正确使用语句实现用户定义的完整性。

### 4.  本章重点、难点

本章的重点：掌握创建和删除 PRIMARY KEY 约束、UNIQUE 约束、FOREIGN KEY 约束、CHECK 约束的语句和方法。

本章的难点：使用 CREATE TABLE 语句、ALTER TABLE 语句分别创建和删除 PRIMARY KEY 约束、UNIQUE 约束、FOREIGN KEY 约束、CHECK 约束。
