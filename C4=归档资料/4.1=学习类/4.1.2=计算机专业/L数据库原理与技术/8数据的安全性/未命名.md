## 8.  安全管理

### 1.  学习目的与要求

本章主要学习 MySQL 权限表、用户管理、权限管理等内容。

本章要求考生掌握 CREATE USER 语句、DROP USER 语句、RENAME USER 语句、SET PASSWORD 语句，具备使用上述语句分别创建用户、删除用户、修改用户账号、修改用户口令的能力；掌握 GRANT 语句、REVOKE 语句，具备使用上述语句分别授予权限、撤销权限的能力。

### 2.  课程内容

1.  权限表

2.  用户管理

3.  权限管理

### 3.  考核知识点与考核要求

#### 1.  权限表

识记：MySQL 权限表所在的数据库名；权限表包括哪些表。

#### 2.  用户管理

识记：用户管理包含的操作及其使用的语句。

简单应用：能正确使用 CREATE USER 语句、DROP USER 语句、RENAME USER 语句、SET PASSWORD 语句分别创建用户、删除用户、修改用户账号、修改用户口令。

#### 3.  权限管理

识记：权限管理包含的操作及其使用的语句。

领会：MySQL 可以授予的权限包含的组类及每组的含义；用户指定权限级别的值的格式及其含义。

简单应用：能正确使用 GRANT 语句、REVOKE 语句分别授予权限、撤销权限。

### 4.  本章重点、难点

本章的重点：创建用户、删除用户、修改用户账号、修改用户口令的语句和方法，授予权限、撤销权限的语句和方法。

本章的难点：正确有效的 CREATE USER 语句、DROP USER 语句、RENAME USER 语句、SET PASSWORD 语句分别创建用户、删除用户、修改用户账号、修改用户口令；正确有效地使用 GRANT 语句、REVOKE 语句分别授予权限、撤销权限。
